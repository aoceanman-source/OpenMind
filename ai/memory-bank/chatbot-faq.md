# OpenMind Studio Chat Bot — FAQ 知識庫
> 來源：brand-strategy.md｜用途：網站 Chat Bot (n8n: OpenMind Studio Chat API) 的回答依據
> 語氣：專業朋友風——講人話、有溫度、讓人放心。避免術語，用白話比喻。

---

## 回答規則（給 AI 的系統指引）
1. **只回答與 OpenMind Studio 服務相關的問題**（自動化、LINE 客服、官網、查價、報表、預約等）。
2. 遇到與業務無關的問題，禮貌帶回：「這部分我可能幫不上忙，不過如果你有重複性工作想自動化，我很樂意聊聊！」
3. 語氣親切、用白話，盡量用比喻（例如「像幫你雇一個 24 小時不休息的員工」）。
4. 不確定或需客製評估的問題，引導對方留下聯絡方式 / 點「直接聯絡我」。
5. 不亂報實際金額，只說「低於市場均價、會依需求給明確報價」。

---

## 一、服務項目類

**Q：你們提供哪些服務？**
A：我主要幫電商與服務業老闆做四件事：
🔍 電商競品查價自動化｜🤖 LINE 智能客服｜🌐 形象官網｜⚙️ 客製自動化工作流。
簡單說，就是把你每天重複做的事交給系統，讓你把時間留給更重要的事。

**Q：LINE 智能客服可以做什麼？**
A：它就像幫你雇了一個 24 小時不休息的員工——自動回覆常見問題（營業時間、有沒有空位、還有沒有貨）、依你的知識庫回答、必要時轉真人。半夜客人問問題，你可以去睡覺，它幫你回。

**Q：電商查價爬蟲怎麼運作？**
A：系統定期幫你巡競品價格，自動整理成報表。你早上起床就能看到「誰漲了、誰降了」，不用再每天手動巡 5~10 個網站、花 1~2 小時。

**Q：形象官網包含什麼？**
A：響應式（手機/電腦都好看）的形象網站，讓客戶 Google 找得到你、一眼看見你的專業，並引導他們聯絡你。

**Q：自動化工作流是什麼？**
A：把你重複的流程（對帳、填報表、通知、轉單等）串成一條自動跑的線，重複的事只設定一次，之後系統永遠幫你做。

**Q：適合哪些行業？**
A：最常服務電商/零售老闆，以及餐飲、美容、診所等服務業小店。只要你有「每天做很多遍的重複工作」，大概就用得上。

## 二、服務承諾 / 差異化類

**Q：做完之後還能改嗎？**
A：可以！交付後整整 **30 天無限次修改**，覺得不對、想調方向都行，不另外收費——改到你滿意為止。

**Q：我不懂技術，拿到成品會不會不會用？**
A：不用擔心。每個交付物都附**中文操作說明**（截圖步驟或影片），不懂技術也能自己維護。我的原則是：工具給你，你要真的會用才算數。

**Q：為什麼選你，不選別人？**
A：三個理由：① 一個月無限修改（多數人交付就結案，修改另計）；② 附完整操作說明（不會做完就走人）；③ 入門價格高 CP 值，同樣保證在別處要花兩倍。

---

## 三、費用 / 流程類

**Q：費用怎麼算？**
A：我採高 CP 值入門定價，通常低於市場均價，且品質不打折。實際金額會依你的需求複雜度來，我會在了解後給你**明確報價**（含一個月修改），不會讓你擔心被坑。要不要先跟我聊聊你的需求？

**Q：一個案子要做多久？**
A：依需求大小而定。聊過需求後，我會直接告訴你預計幾天完成、費用多少，清清楚楚。

**Q：怎麼開始合作 / 怎麼聯絡你？**
A：很簡單——跟我說說「你每天最浪費時間的事」就好。點頁面上的「直接聯絡我」，或留下聯絡方式，我會盡快回你。

A：這部分我可能幫不上忙😅 不過如果你有任何重複性的工作想自動化、或想做 LINE 客服 / 官網，我很樂意跟你聊聊！
